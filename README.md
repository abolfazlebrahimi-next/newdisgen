# LOCO — شهر بازی (Next.js + TypeScript)

بازسازی صفحهٔ بازی **LOCO** (تصویر مرجع) به‌صورت یک اپ واقعی **Next.js (App Router) + TypeScript + three.js**،
با استفاده از **مدل‌های سه‌بعدی Kenney که همین حالا داخل این مخزن هستند**.

> این مخزن در ابتدا هیچ کد اپ نداشت؛ فقط سه بستهٔ دارایی سه‌بعدی Kenney بود
> (`kenney_retro-urban-kit`، `kenney_tower-defense-kit`، `kenney_mini-characters`,
> به‌همراه `Model/`، `Animations/` و `Skins/`). بنابراین کل اپ دور همین دارایی‌ها ساخته شده است.

---

## اجرا

```bash
npm install
npm run dev          # http://localhost:3000  (روی 0.0.0.0 بایند می‌شود تا در پیش‌نمایش هم کار کند)
```

اسکریپت‌های کمکی:

| دستور | کار |
| --- | --- |
| `npm run assets:sync` | کپی مدل‌ها/تکسچرهای لازم از بسته‌های Kenney به `public/assets/models` |
| `npm run assets:measure` | اندازه‌گیری ابعاد هر مدل (`tmp-render/measure.json`) برای چیدن دقیق ساختمان‌ها |
| `npm run preview:render` | رندر آفلاین کل شهر (بدون مرورگر) در `tmp-render/town.png` |
| `npm run preview:pieces` | شیت رندر تک‌تک مدل‌ها برای بررسی جهت و اندازه |
| `npm run smoke` | تست دود مسیر هندسهٔ سمت مرورگر (ادغام، رنگ‌ها، دوربین) |
| `npm run check` | `tsc --noEmit` + تست دود |
| `npm run build` | بیلد پروداکشن |

`assets:sync` خودکار قبل از `dev` و `build` اجرا می‌شود. فایل‌های کپی‌شده git-ignore هستند،
منبع اصلی همان پوشه‌های بسته در ریشهٔ مخزن است.

## چه چیزی ساخته شده

### صحنهٔ سه‌بعدی (`src/components/scene/`)
* **شهر کامل روی گرید ۱×۱**: خیابان اصلی سه‌کاشی، خیابان عرضی، پیاده‌رو، جدول، خط‌کشی،
  خط‌عابر، پل، مانهول، چاله و لکهٔ آسفالت.
* **شهربازی**: رولرکوستر با ریل وپایه‌های واقعی (منحنی بستهٔ تپه‌دار)، چرخ‌فلک با ۸ کابین
  (کابین‌ها همیشه صاف می‌مانند)، چرخ‌فلک و چرخ‌فلک‌های چرخان از طریق گروه‌های حرکتی (kinematic)،
  سیرک، چرخ‌وسایل، دکه‌ها، بادکنک، دروازهٔ ورودی.
* **بیمارستان لینا**: ساختمان دوطبقه با صلیب فیروزه‌ای، سایبان ورودی، رمپ و خط‌کشی آمبولانس.
* **مزرعه**: دو مزرعهٔ شیاردار، انبار+سیلو، قلاب‌های کاه، گوسفندها، پادوک، کامیون.
* **ردیف خیابانی**: مکانیکی (با ماشین روی جک، لاستیک، مخروط)، باشگاه (دمبل بیرونی)،
  کلانتری (بنر و چراغ گردان و مارکر «!»)، فروشگاه‌ها با سایبان و میز کافه.
* **محله‌ها**: خانه‌های دوطبقه، کارگاه ساخت‌وساز با اسکافولد، خانه‌های پشت خیابان، زمین بازی
  کودکان (سرسره، تاب، سندباکس)، میدان با آب‌نما، بازار روز.
* **ترافیک و عابرها**: ۶۳ بازیگر؛ ماشین‌ها روی مسیر بسته در دو لاین، ۵۰+ عابر که
  کلیپ‌های **walk/idle** پک را بازی می‌کنند و دو ویلچر با کلیپ `wheelchair-move-forward`.

### چیدمان به‌صورت داده، نه کد صحنه
کل شهر یک لیست داده است: `src/game/layout/town.ts` → `buildTown()`.
هر آیتم یک «part» است (مدل کیت یا primitive) و همین یک منبع، هم در مرورگر و هم در
رندر آفلاین استفاده می‌شود:

```
src/game/layout/
  types.ts       مدل داده (Part / ActorSpec / LabelSpec / MarkerSpec)
  core.ts        TownBuilder (pos = مرکز پایه)، RNG قطعی
  palette.ts     رنگ‌ها؛ پک‌ها بی‌رنگ‌اند و همه‌چیز با tint رنگ می‌گیرد
  buildings.ts   سازندهٔ ساختمان: دیوار/پنجره/سقف/سایبان روی گرید کیت
  rides.ts       چرخ‌فلک، رولرکوستر، سیرک، چرخ‌وسایل، دکه
  props.ts       ماشین، آب‌نما، چراغ، نیمکت، حوض، درخت…
  town.ts        ترکیب نهایی شهر (تمام اعداد چیدمان همین‌جاست)
```

### UI (HUD)
کامپوننت‌های جدا در `src/components/hud/`: کارت بازیکن، نوار سکه/شبنم، داک دکمه‌های گرد،
کارت هدیهٔ ۵٬۰۰۰ سکه/۱٬۲۵۰ شبنم، کارت ساختمان‌ها، پنل‌ها (کارها، کوله‌پشتی، پیام‌ها، فروشگاه، تنظیمات)
و توست‌ها، با استیت `zustand` (`src/store/game.ts`) + ذخیره در localStorage.

استایل کارتونی در `src/app/globals.css` به‌صورت چند کلاس مشترک:
`.loco-panel` (کارت کرم با لبهٔ چوبی)، `.loco-plate` (پلاک فلزی آبی)، `.loco-btn`،
`.loco-circle`، `.loco-ribbon`. فونت فارسی: **Vazirmatn** (self-host).

### تابلوها و مارکرها
متن فارسی تابلوها به‌جای تکسچر، **DOM** است و با دوربین پروجکت می‌شود
(`.loco-label-layer`) — پس همیشه واضح است و با زوم مقیاس می‌گیرد؛ برای مارکر مأموریت هم همان روش.

## بهینه‌سازی
* همهٔ قطعات ثابت **بر اساس تکسچر ادغام** می‌شوند (کشور ~۲۰ draw call برای ۲٬۸۰۰+ قطعه).
* هر primitive یک تکسچر پیدا می‌کند (`urban/grass`، `urban/asphalt`…)، بقیه vertex-color خالص‌اند.
* ۵۹ مدل GLB (از ۳۱۰ مدل موجود) داخل `public/assets/models` سرو می‌شود؛ ~۳ مگابایت.
* چرخ‌فلک/چرخ‌وسایل/قطار به‌صورت گروه‌های چرخان جدا رندر می‌شوند، پس ادغام استاتیک را خراب نمی‌کنند.

## چگونه بدون مرورگر صحنه را دیدم
محیط این تسک مرورگر headless نداشت (Chromium بدون `libnspr4` بالا نمی‌آمد)، بنابراین
یک **رندر نرم‌افزاری کوچک** نوشتم که همان داده‌های چیدمان را می‌خواند و با همان دوربین
orthographic تصویر می‌سازد:

```
scripts/lib/gltf.mjs      خوانندهٔ GLB (POSITION/NORMAL/UV/indices + KHR_texture_transform)
scripts/lib/build.mjs     ساخت primitiveها (box/cylinder/cone/sphere/torus/circle)، stripe، transform stack
scripts/lib/raster.mjs    رسترایزر نرم‌افزاری (zbuffer، facet، gradient sky)
scripts/lib/emit.mjs      ترجمهٔ Part → هندسه
scripts/render.mjs        رندر کل شهر با fit خودکار دوربین
scripts/piece-sheet.mjs   شیت مدل‌ها برای بررسی جهت
```

خروجی این ابزار در `tmp-render/` ذخیره می‌شود و فقط برای بازبینی است (git-ignore).

## نکته‌های فنی/هنری که ارزش دانستن دارند
* در کیت‌ها **مدل‌ها z-up هستند ولی یونیتی آن‌ها را به y-up می‌چرخاند**؛ یعنی «دیوار» یک مکعب
  روی گرید است و `wall-a-flat-window` عمودی می‌ایستد (از `scripts/measure-models.mjs` استخراج شد).
* تکسچرهای کیت تیره و ژولیده‌اند (میانگین تیرهٔ چمن ۲۸٪ و آسفالت ۲۴٪)؛ برای رسیدن به ظاهر
  کارتونی LOCO همه‌چیز با `PALETTE` (مقادیر بزرگ‌تر از ۱) ضرب می‌شود.
* رنگ sRGB روی `map` ست می‌شود و رندرر روی `SRGBColorSpace` است، نورپردازی هم با
  رندرر آفلاین یکی نگه داشته شده تا پیش‌نمایش و مرورگر یکی باشند.
* کلیپ‌های انیمیشن کاراکترها از خود GLB می‌آیند (`walk`, `idle`, `wheelchair-move-forward`).
* مدل‌های کم‌ارتفاع/کم‌پلی مثل `Model/characterMedium.fbx` + `Animations/*.fbx` + `Skins/*.png`
  (نسخهٔ FBX/rigged) در این اپ استفاده نشده‌اند چون GLTFLoader آن‌ها را نمی‌خواند؛ به‌جایشان
  نسخهٔ GLB همان کاراکترها با ۳۲ کلیپ انیمیشن استفاده شده است.
